# Security policy

Report suspected vulnerabilities privately to **skaneprime@gmail.com** (Ali Aliyev).
Include affected versions, a minimal reproduction with synthetic data and the likely
impact. Do not include live tokens, passwords, invitation links or private workspace
content. Do not access another person's data, disrupt the hosted service or publish
exploit details before coordinated review.

The project currently maintains the latest source revision and hosted release; there
is no long-term-support release schedule or guaranteed response time. This policy
is not a promise of a bug bounty or authorization to attack third-party infrastructure.

For access, deletion, abuse or copyright requests, use the same contact with the
relevant subject and minimal identifying details. See [legal readiness](docs/legal-readiness.md)
for the hosted-service policy review status.
